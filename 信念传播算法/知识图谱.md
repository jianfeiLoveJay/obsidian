## 一、理论基石

### 1.1 因子图与和积算法

- 全局函数分解 → 因子图表示
- 消息更新：变量节点传乘积，因子节点传"乘后求和"
- 半环推广：Sum-Product / Max-Product / Min-Sum

已读：[[阅读笔记/01_因子图与和积算法_Kschischang2001.md|📖 Kschischang 2001]]

### 1.2 广义分配律

- 代数半环角度统一消息传递
- 因子图 = GDL 的可视化载体

已读：[[阅读笔记/02_广义分配律_AjiMcEliece2000.md|📖 Aji & McEliece 2000]]

### 1.3 最优性与不动点

- 有环图上 Max-Product 不动点 = **邻域最大值**（非全局）
- 建立 BP 不动点与 LP 极值点的对应

已读：[[阅读笔记/16_最优性_Weiss2001.md|📖 Weiss & Freeman 2001]]

## 三、收敛性全景图

```
无环图
  └── 所有 BP → 精确解 (Kschischang 2001)

有环图 → 以下条件满足其一即可收敛
  ├── 唯一最优解 → Cheng 2006, Bayati 2008, Gamarnik 2012, Dai 2022
  ├── LP 松弛无分数解 → Even 2015, Bayati 2011, Sanghavi 2011
  ├── 全幺模约束矩阵 → Ruozzi 2008
  └── 否则 → BP 可能振荡或收敛到非最优不动点 (Weiss 2001, MWIS)
```

## 五、核心洞察

1. **统一性**：20+ 种算法都是消息传递在不同半环/图结构上的特例
2. **精确性**：无环图保证精确解；有环图需额外条件
3. **LP 桥接**：BP 不动点 ⇔ LP 对偶解（核心理论联系）
4. **实用性**：即使无理论保证，BP 在 turbo/LDPC/计算机视觉中极其成功
