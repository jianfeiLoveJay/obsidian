# 信念传播算法学习工作流

> 本文档说明如何使用本 vault 进行 23 篇论文的系统学习。

---

## Vault 结构

```
research/信念传播算法/
├── 邮件内容.md                           # 导师建议邮件
├── papers/                               # 原始PDF（不修改）
│   ├── (1)2006[Cheng].pdf
│   ├── (1)_[1]Factor_graphs.pdf
│   └── ...
├── 论文研读/                             # 你的学习笔记
│   ├── _论文研究索引.md                   # 23篇论文总览索引
│   ├── 因子图与和积算法.md                # 每篇论文的学习笔记
│   ├── 广义分配律.md
│   ├── ...
│   └── 模板/
│       └── 读书笔记模板.md                # 笔记模板
```

## 核心工作流

1. 打开 [[_论文研究索引.md|研究索引]] 选择论文
2. 点击对应的 stub 笔记开始学习
3. 按进度清单逐项完成
4. 在"与其它论文的联系"部分建立 wikilink

当你开始学习一篇论文时，告诉我即可。我会帮你梳理背景、解释推导、引用其他论文进行对比。
