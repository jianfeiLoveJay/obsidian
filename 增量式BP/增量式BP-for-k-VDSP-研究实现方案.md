## §0 一页纸汇报稿（先看这一页）

### 0.1 一句话目标

在 Dai 2022（P22）的 Min-Sum BP 框架上，构造**增量式 BP**：当图结构、弧权或需求量 k 发生局部变化（或需求实时变化）时，**复用上一轮收敛的 δ 消息作为热启动**，只重算受影响的局部区域，并以**残差驱动的异步调度**推进，从而把「每次变化全图重算」降为「局部增量维护」，同时**严格保持与冷启动 BP 相同的不动点**。

### 0.2 三点贡献（可写进汇报的骨架）

|---|---|---|---|

| **C2** | 三档增量机制 | 档 A 残差驱动调度、档 B warm-start + 影响区域、档 C 结构/参数变化；三档**正交可叠加**，正确性统一由不动点不变性兜底 | I1/I2/I3/I6（档 A）、I7/I8/I13（档 B）、I9/I10/I11/I12 + P22 §V（档 C） |

### 0.3 关键判断（汇报时必须先讲的三条）

1. **基线论文的收敛证明可用，但工程定义缺失**：P22 未严格给出消息初值、调度方式、停止判据（笔记里已记录该问题）。Dai 的定理对**任意合理性调度**都有效，这恰好给增量式调度留出了合法空间——本方案的档 A 就是补这个洞。
2. **增量式的卖点不是"更快求解"而是"更低的重解代价"**：P22 §VI 自己承认运行时间不优于已有算法。因此增量式的价值必须落在**动态图实时重解 / 摊销代价 / 分布式本地更新**上，而不是"打败 Suurballe/费用流"。实验设计（§5）必须围绕这一点。
3. **风险预警：P22 的 NP-难表述与经典结论存在张力，需向导师确认**。P22 引言称 "k-VDSP is strongly NP-hard when k ≥ 2 [16]"，其引文 [16] 是 Itai–Perl–Shiloach 1982（**带长度约束**的不相交路径）；而 P22 自己又把问题溯源到 Suurballe 1974——**无长度约束的最小总权 k 条内部不相交 s-t 路径是多项式可解的**（拆点 + 最小费用流，即 Suurballe 方法）。这一条直接决定研究定位：
   - 若研究目标 = 无长度约束的 k-VDSP ⇒ 贡献只能在**增量/动态/分布式**侧，不能宣称"首个 NP-难问题的 BP 正确性"。
   - 若研究目标 = **带长度约束**的 k-VDSP（真正 NP-难）⇒ BP 只能当启发式，此时"增量式 + anytime 实时重规划"的价值最大，也最像一篇独立小论文。

## §1 基线：Dai 2022（P22）的完整复述（增量式的地基）

> 这一节的作用：先把基线钉死。P22 写作质量差，若不复述清楚，后面所有增量设计都会悬空。

### 1.1 问题与整数规划形式

输入：有向加权图 G = (V, E, w)，n = |V|、m = |E|，w(e) ≥ 0；源 s、汇 t；整数 k ≥ 1。
目标：求 k 条**内部顶点不相交**的 s-t 路径 P₁, …, Pₖ，使 Σᵢ w(Pᵢ) 最小。
假设（P22 §II-A 明文假设）：N⁻(s) = ∅（源无入弧）、N⁺(t) = ∅（汇无出弧）。

P22 的 IP（式 (1)–(5)，原文编号）：

- 目标：min Σ(e∈E(G)) w(e) · x(e)
- 式(2) 源汇度：Σ(j∈N⁺(s)) x(sj) = k，Σ(j∈N⁻(t)) x(jt) = k
- 式(3) 内部守恒：Σ(j∈Nᵢ⁺) x(ij) − Σ(j∈Nᵢ⁻) x(ji) = 0，∀ i ∈ V ∖ {s,t}
- 式(4) 内部度约束：Σ(j∈Nᵢ⁺) x(ij) + Σ(j∈Nᵢ⁻) x(ji) ∈ {0, 2}，∀ i ∈ V ∖ {s,t}
- 式(5) x(e) ∈ {0,1}

等价写法（P22 §II-A 后段）：定义**顶点需求函数** f: V(G) → Z，
f(s) = k，f(t) = −k，f(i) = 0（i ≠ s,t）；
则约束改写为 Σ(j∈Nᵢ⁺) x(ij) − Σ(j∈Nᵢ⁻) x(ji) = f(i)（∀i），内部顶点再加 Σx ≤ 2 与 (3)(5) 联立。

**关键洞察（C2 档 C 的立足点）**：f 只出现在 s 与 t 的约束里。内部顶点的局部约束**完全不含 k**——这是"k 变化只重算 s/t 消息"的全部理由。

### 1.2 因子图构造（P22 §III-A）

- **变量节点** = 弧 e ∈ E(G)，取值 x(e) ∈ {0,1}
- **因子节点** = 顶点 i ∈ V(G)，约束函数 ψᵢ
- 边 (e, i) 存在 ⟺ e 与 i 关联；Eᵢ = 与 i 关联的弧集，x(Eᵢ) = {x(e) : e ∈ Eᵢ}

变量函数（一元代价）：φ(e)(x(e)) = w(e) · x(e)，若 x(e) ∈ {0,1}；否则 φ(e) = +∞。

因子函数（P22 §III-A 原文分段定义）：

- i = s 或 t：ψᵢ(x(Eᵢ)) = 0 若 Σ(j∈Nᵢ⁺) x(ij) − Σ(j∈Nᵢ⁻) x(ji) = f(i)；否则 +∞
- i ∈ V ∖ {s,t}：ψᵢ = 0 若 Σ(j∈Nᵢ⁺) x(ij) = Σ(j∈Nᵢ⁻) x(ji) 且 Σ(j∈Nᵢ⁺) x(ij) + Σ(j∈Nᵢ⁻) x(ji) ≤ 2；否则 +∞

于是 k-VDSP 等价于**因式分解优化问题**：
min Σ(e∈E(G)) φ(e)(x(e)) + Σ(i∈V(G)) ψᵢ(x(Eᵢ))，s.t. x(e) ∈ {0,1}。

### 1.3 消息规则（P22 式 (6)(7)，Algorithm 1 第 3 行）

对弧 e = ij（起点 i、终点 j）定义两条半消息：

- **弧 → 顶点**（变量→因子）：m(e→j)(x(e)) = φ(e)(x(e)) + m(i→e)(x(e))　… (6)
- **顶点 → 弧**（因子→变量）：m(i→e)(x(e)) = min over x(Eᵢ∖e) [ ψᵢ(x(Eᵢ)) + Σ(e′∈Eᵢ∖e) m(e′→i)(x(e′)) ]　… (7)

互补方向同理：m(e→i)(x(e)) = φ(e)(x(e)) + m(j→e)(x(e))（i 的对侧是 j）。这一点 P22 没显式写出，P22 式(6)只写了 m(e→j)，但 Algorithm 1 第 6 行的信念定义 b(e) = m(e→i) + m(e→j) − φ(e) 用到了 m(e→i)，故必须补上这条对称式。

**信念与判决**（Algorithm 1 第 6–8 行）：
b⁽Q⁾(e)(x(e)) = m⁽Q⁾(e→i)(x(e)) + m⁽Q⁾(e→j)(x(e)) − φ(e)(x(e))；
x⁽Q⁾(e) 取使 b⁽Q⁾(e) 最小的取值（在 x(e) ∈ {0,1} 上取 argmin）。

### 1.4 Algorithm 1 逐行（并标注它没写清的地方）

| 行 | 原文动作 | 缺口 |
|---|---|---|
| 1 | Initialize m⁰(i→e)(x(e)) = 0（对全部 i, e） | 零初始化没给理由；对 min-sum 而言对应"无信息先验"，但**对源/汇的 top-k 语义为空**是隐患 |
| 2–5 | 对 q = 1..Q 同步更新全部半消息 | 只给同步调度；未讨论异步，也没给停止判据 |
| 6–8 | 算信念、取 argmin、返回 x⁽Q⁾ | 未定义输出不可行时的处理 |
| — | 未定义 | **eps / 收敛判据 / 数值尺度**全部缺失 |

### 1.5 残差网络、计算树与两个定理

**残差网络 Gˣ**（P22 §III-C）：V(Gˣ) = V(G)；对每条 e = ij ∈ E(G)：若 x(e) = 0，则 e = ij 以权 w(e) 留在 Gˣ；若 x(e) = 1，则加入**反向弧** ji，权为 −w(e)。

**计算树 T⁽Q⁾(r)**（P22 §II-B）：以弧 r 为根、深度 Q 的 BFS 展开树（允许顶点重复）；每个顶点/弧都是 G 中某元素的副本；映射 γ 回到原图。**核心事实（Lemma 3）**：BP 第 Q 轮的输出 x⁽Q⁾(r) 恰等于计算树 T⁽Q⁾(r) 上诱导问题 VDSP(T⁽Q⁾(r)) 的最优解在第 Q 层的取值。即「有环图上第 Q 轮 BP = 深度 Q 树上精确解」。

**Theorem 1（P22）**：若 k-VDSP on G 有唯一最优解 x⋆，则 Min-Sum BP 在 (⌈U / (2·o(x⋆))⌉ + 1)·n 轮内收敛到 x⋆。其中 U = G(x⋆) 中最重**简单有向路径**的权重，o(x⋆) = G(x⋆) 中最轻**有向环**的权重。

**Corollary 2（P22）**：若各弧权为非负整数，则收敛轮数为 O(n² wₘₐₓ)，其中 wₘₐₓ = max{w(e)}。

**证明骨架（对增量式很关键）**：假设某轮 x⁽Q⁾ ≠ x⋆ → 由 Lemma 3 得到计算树上的最优解 y⋆ → 与 x⋆ 的差异沿计算树向下的弧逐层延拓，拼出一条长度 2Q+1 的 walk P → P 在 G(x⋆) 上分解为 1 条简单路径 D（权 ≥ −U）与 d 个简单有向环（每个权 ≥ o(x⋆)）→ 当 Q ≥ (⌈U/(2o(x⋆))⌉+1)n 时 d > U/o(x⋆)，于是 w(P) > 0，与 y⋆ 最优矛盾。

**为什么这段骨架对增量式是"好消息"**：整条证明只用到「树上的部分解 → 投影回残差网络 → 环计数」，**完全不依赖消息的初值与调度方式**。因此只要（a）调度是"合理的"（无饥饿：每条待更新消息最终都会被更新），（b）不再更新时到达的是 BP 的不动点，定理的轮数上界就依然成立——这是档 A 的合法性来源（对应 #2 GDL 的调度定理与 I1 的异步收敛定理）。

### 1.6 多源/多汇扩展（P22 §V）——档 C 的接口

| 版本 | f 的定义 | 度约束作用域 |
|---|---|---|
| 多源（S = {s₁..sₖ}，单汇 t） | f(t) = −k，f(i) = 1（i ∈ S），其余 0 | V ∖ ({t} ∪ S) |
| 多汇（单源 s，T = {t₁..tₖ}） | f(s) = k，f(i) = −1（i ∈ T），其余 0 | V ∖ ({s} ∪ T) |
| 多源多汇（S 与 T 各 k 个） | f(i) = 1（i ∈ S），f(i) = −1（i ∈ T），其余 0 | V ∖ (S ∪ T) |

P22 只声明"证法不变，证明省略"。**这正是我们要补的**：局部消息规则必须按 f 重写（见 §2.2 表末行）。P22 未给出的部分，恰好是增量式的接口。

### 1.7 基线论文的 5 个薄弱点（= 我们的入口）

1. **消息初值语义不清**：零初始化对内部顶点是无信息先验，对 s/t 的 top-k 语义则需重新解释。
2. **无调度理论**：只给同步调度；未讨论异步/残差/并行。
3. **无停止判据**：没有 eps、没有残差阈值、没有唯一性检测。（对比 #16/#17 Gamarnik 2012 推论 5.2 给了整数数据下的唯一性检测。）
4. **Lemma 4 证明跳跃**：交替路径的延拓与"3 种取向情形"验证在原文中压缩严重，需自行补全（这也是我们要独立实现对拍的原因）。
5. **无任何实验**：P22 通篇没有实验章节，只有理论。⇒ 我们的实验章从零开始，且**必须自带精确基线**。

## §2 建模层修正 C1：从"二元消息函数"到"单标量 δ"（含完整推导）

> 这一节是全部工程实现的地基。P22 的消息是**函数**（值域在 {0,1} 上，即 2 个实数）；本节证明它可以无损压缩成**1 个实数**，并给出闭式局部更新式。

### 2.1 符号约定

| 符号 | 含义 |
|---|---|
| e = (a, b) | 有向弧，**尾 a、头 b** |
| IN(i) / OUT(i) | i 的入弧集 / 出弧集（即 Nᵢ⁻ / Nᵢ⁺ 的弧形式） |
| E(i) | IN(i) ∪ OUT(i) |
| δ(i→e) | 因子→变量半消息的差：m(i→e)(1) − m(i→e)(0)（"顶点 i 对弧 e 的态度"） |
| δ(e→i) | 变量→因子半消息的差：m(e→i)(1) − m(e→i)(0)（"弧 e 报给端点 i 的代价差"） |
| Δ(e) | 信念差 b(e)(1) − b(e)(0) |
| pᵢₙ / pₒᵤₜ | min over a∈IN(i) δ(a→i) / min over b∈OUT(i) δ(b→i)（顶点 i 视角） |
| 上标 −e | 表示"从该集合/最小中排除 e" |
| T(j, S) | 集合 S 中**最小的 j 个元素之和**；若 j = 0 则为 0；若 ｜S｜ < j 则为 +∞ |

### 2.2 引理 1（标量充分性）——为什么可以只存一个数

**命题**：min-sum 消息系统具有**平移不变性（gauge invariance）**。若把所有进入顶点 i 的入消息统一加常数 c(e′)（即 m(e′→i) ← m(e′→i) + c(e′)），则出消息 m(i→e) 整体被平移 Σ(e′∈Eᵢ∖e) c(e′) —— **一个与 x(e) 无关的常数**。

**证明**：由式(7)，
m(i→e)(x(e)) = min over x(Eᵢ∖e) [ ψᵢ(x(Eᵢ)) + Σ(e′∈Eᵢ∖e) m(e′→i)(x(e′)) ]。
把每个 m(e′→i) 换成 m(e′→i) + c(e′)，被 min 的表达式整体加了 Σ(e′) c(e′)（与 x(Eᵢ∖e) 无关），故 min 的结果等于原值加同一常数。∎

**推论**：每条消息（∈ R²）只由**差** m(1) − m(0) 决定其"有效信息"；绝对偏移在后续所有 min、加法、以及信念差 Δ(e) 中都会被抵消。

**工程含义（三条收益）**：
1. 内存：每条半消息 2 个 double → **1 个 double**（-50%）。
2. 算术：式(7) 的 min 运算退化为 §2.3 的**闭式加减法**，不再需要枚举赋值。
3. 数值：δ 天然是"相对量"，跨迭代不会累积无意义的大偏移（配合 §4.3 的整体平移归一化）。

**来源对位**：
- 标量化先例：#6 Cheng 2006（标量消息 + 阈值判定）、#9/#10 BSS 简化 min-sum（n 维向量 → 标量）、#13 BBCZ 2011（顶点-顶点标量消息）。
- "消息仅差量有意义"的思想在 #2 GDL 的半环框架下即"消息在等价类下定义"；本引理是它在 min-sum 上的具体化。
- 与 #16/#17 Gamarnik 2012 的对比：那里消息是**分段线性凸函数**（要用函数插值实现），本文消息空间退化为"二元函数"，因此凸性自动成立、无需插值。

### 2.3 引理 2（局部闭式更新）——四种顶点规则

#### (1) 跨弧传播（唯一的"非局部"一步）

对 e = (a, b)，由式(6)：m(e→b)(x(e)) = φ(e)(x(e)) + m(a→b 的尾 a → e)(x(e))，
取差即得：

- δ(e→b) = w(e) + δ(a→e)
- δ(e→a) = w(e) + δ(b→e)

统一写法：**对 e 的两个端点 i 与 j（j 为另一端）：δ(e→i) = w(e) + δ(j→e)**。

> 直觉：弧 e 报给端点 i 的"代价差"= 弧自身权重 + 另一端对 e 的态度。这就是"价格沿弧传播"。

#### (2) 内部顶点（f(i) = 0，度 ≤ 2）

可行赋值只有两种：全 0；或"恰 1 条入弧 + 恰 1 条出弧"。
注意 **m(e→i) 不出现在式(7) 的求和里**，所以计算 m(i→e) 时 e 自身的代价差**不计入**。

**情形 A：e ∈ IN(i)**（e = (a, i)）

- 取 x(e) = 1：入侧已由 e 满足 ⇒ 出侧必须恰选 1 条 b ∈ OUT(i)，代价 min over b δ(b→i) = pₒᵤₜ。故 value(1) = pₒᵤₜ。
- 取 x(e) = 0：要么全 0（代价 0），要么另选 a′ ∈ IN(i)∖{e} 与 b ∈ OUT(i) 各一条（代价 δ(a′→i) + δ(b→i)，最小为 pᵢₙ⁽⁻ᵉ⁾ + pₒᵤₜ）。故 value(0) = min( 0, pᵢₙ⁽⁻ᵉ⁾ + pₒᵤₜ )。

**⇒ δ(i→e) = pₒᵤₜ − min( 0, pᵢₙ⁽⁻ᵉ⁾ + pₒᵤₜ )**

**情形 B：e ∈ OUT(i)**（对称）

**⇒ δ(i→e) = pᵢₙ − min( 0, pᵢₙ + pₒᵤₜ⁽⁻ᵉ⁾ )**

**两个易错点**：
- 情形 A 里 pₒᵤₜ **不排除 e**（e 是入弧，不在 OUT(i) 中）；情形 B 里 pᵢₙ 不排除 e。只有"同侧"才需要排除。
- **退化度**：若 OUT(i) = ∅ 而 e ∈ IN(i)，则 value(1) = +∞（选不出出弧），此时 δ(i→e) = +∞，语义是"永远不要选 x(e) = 1"。实现用 BIG（如 1e15）代替 +∞，并在解码时把 Δ(e) < 0 的判定改为"Δ(e) < 0 且非 BIG 溢出"。

#### (3) 源 s（仅出弧，恰 k 条）

- value(1) = T(k−1, OUT(s) ∖ {e})（再选 k−1 条最小的）
- value(0) = T(k, OUT(s) ∖ {e})

**⇒ δ(s→e) = T(k−1, OUT(s) ∖ {e}) − T(k, OUT(s) ∖ {e})**

**语义**：这是"第 k 名与第 k−1 名之间的边际价格"——正是**对偶价格**的离散形式。δ(s→e) 的绝对值越大，说明 s 越"犹豫"要把 e 放进 k 条路径里。

#### (4) 汇 t（仅入弧，恰 k 条）

**⇒ δ(t→e) = T(k−1, IN(t) ∖ {e}) − T(k, IN(t) ∖ {e})**

#### (5) 一般 f-顶点（§V 多源多汇的接口）

| 顶点类型 | 局部规则 |
|---|---|
| 仅出弧，f(i) = q > 0（多源） | δ(i→e) = T(q−1, OUT(i)∖{e}) − T(q, OUT(i)∖{e}) |
| 仅入弧，f(i) = −q（多汇） | δ(i→e) = T(q−1, IN(i)∖{e}) − T(q, IN(i)∖{e}) |
| 内部，f(i) = 0 | §2.3(2) 的 top-2 规则 |
| 双向且 ｜f(i)｜ > 0（P22 假设下不出现） | 需按 (in, out) 枚举可行对（f(i) = 1 时 (1,0), (2,1), …），δ 变成多个候选的 min；**建议 v1 先保持"源汇单向"假设，此项列为扩展** |

> 这一步是 P22 §V 只写"证明省略"的地方；我们把局部规则显式补全，才有了增量式触发器的可计算性。

### 2.4 解码与信念

对 e = (i, j)（尾 i、头 j）：

b(e)(x(e)) = m(e→i)(x(e)) + m(e→j)(x(e)) − φ(e)(x(e))

⇒ **Δ(e) := b(e)(1) − b(e)(0) = δ(e→i) + δ(e→j) − w(e) = w(e) + δ(i→e) + δ(j→e)**

**解码规则**：x(e) = 1 ⟺ Δ(e) < 0（平局取 0，保持"最小权优先"的确定性解码）。

**读法**：δ(i→e) < 0 表示"端点 i 希望弧 e 被选中"（选它更省）；Δ(e) < 0 表示"两个端点都想要、且省下的量超过弧自身权 w(e)"。与 #14 Kuhn 的对偶价格 + 互补松弛、#15 Bertsekas 的 ε-互补松弛完全同构。

### 2.5 数据结构与复杂度（工程核心）

**顶点级缓存**（每个顶点 i 维护一份）：

| 结构 | 内容 | 用途 |
|---|---|---|
| IN 有序表 / OUT 有序表 | {δ(a→i)} / {δ(b→i)}，按值排序（平衡树或"惰性删除的排序数组 + 版本号"） | 前缀和 → T(j, S) |
| top-3 缓存 | (min1, min2, min3) 及各自 argmin | O(1) 求 pᵢₙ⁽⁻ᵉ⁾：若 argmin ≠ e 取 min1，否则取 min2 |

| 溢出标记 | 是否 deg = 1、是否 OUT = ∅ 等 | 退化情形快速分支 |

**复杂度**：

| 操作 | 朴素 | 本方案 |
|---|---|---|
| 单条半消息更新（内部顶点） | O(deg) | **O(1)**（top-3 缓存） |
| 单条半消息更新（含缓存维护） | O(deg) | **O(log deg)** |

## §3 增量式机制设计 C2：三档结构与完整伪代码

### 3.1 三档总览与正交性

| 档 | 触发条件 | 改变的是什么 | 采用的论文 | 机制要点 |
|---|---|---|---|---|
| **A 调度型** | 收敛慢 / 有环振荡 / 想 anytime 输出 | **更新顺序**（不含问题本身） | I1, I2, I4, I5, I3, I6 | 残差驱动异步：每次只更新当前残差最大的半消息；优先队列；阻尼 |
| **B 参数型** | 弧权局部变化、因子/观测变化 | **初值**（warm start） | I2(§4), I8, I7, I13 | 复用上一轮 δ 作初值；用"受影响区域/前沿"限定传播范围 |
| **C 结构型** | 加删弧/点、k 或 f 变化、流式到达 | **问题实例本身** | I9, I10, I11, I12 + P22 §V | 把实例变化翻译成"哪些半消息的初值失效"，其余全部复用 |

**正交性论证（写进汇报的关键）**：BP 的不动点集合只由三元组 (G, w, f) 决定。档 A 改变的是"沿哪条路径逼近不动点"，档 B 改变的是"从哪个点出发逼近"，二者都不改变"逼近到哪个点"；档 C 则是**换了一个新实例**，此时档 B 的 warm start 是把旧实例的不动点当作新实例的初值——正确性由新实例自身的唯一性条件与档 A 的收敛保证共同兜底。因此三档可以自由叠加：**(A 的调度) × (B 的热启动) × (C 的实例变化)**。

**统一的正确性兜底**：无论怎么叠加，只要满足"无饥饿（每条待更新消息最终被更新）+ 停止时残差为零"，算法停在的必然是 (G, w, f) 的 BP 不动点；再由 P22 定理 1 在唯一最优条件下保证该不动点 = x⋆。

### 3.2 档 A：残差驱动异步调度

#### A-1 残差定义与主循环（I1 核心）

- 残差：**r(i→e) := ｜δ(new)(i→e) − δ(old)(i→e)｜**（标量化后就是绝对差）
- I3 Casado 式(3) 给的是同一思想的范数形式：r(mₖ) = ‖fₖ(m) − mₖ‖，并指出"随着 BP 收敛，更新前后消息之差趋于零，因此残差大的消息最值得更新"。
- 主循环：最大堆取队首 → 用 §2.3 的闭式重算 → 若 ｜Δ(e)｜ ≤ eps 则跳过 → 否则阻尼后写回，并把**受影响的邻居半消息**以各自的新残差入队。

#### A-2 阻尼（damping）与不动点不变性

δ ← (1 − λ)·δ(old) + λ·δ(new)，λ ∈ (0, 1]（推荐 λ = 0.5 起）。

- 不动点不变：若 δ(old) = δ(new)（已是不动点），则阻尼后仍等于它 ⇒ **阻尼不移动不动点，只抑制振荡**。
- 依据：#5 Weiss&Freeman 的不动点方程视角 + 本方案 §4.1 的不动点不变性引理。

#### A-3 四个加速变体（按性价比排序）

| 变体 | 来源 | 做法 | 收益 | 代价 |
|---|---|---|---|---|
| **RBP0L（残差估计）** | I2 §3–§4 | 不真算消息来定优先级，而用**上界估计**：待更新消息的残差 ≤ 其入消息残差的（按度数缩放的）组合 | 减少"只为了算优先级而白算"的消息（I2 称可快至 5 倍） | 需要维护估计值与真实值的偏差 |
| **Quiet（静默剪枝）** | I6 | 当某半消息的残差为 0 且其入消息自上次更新后未变，则**跳过且不再入队**，直到入消息再次变化才唤醒 | 稳态/局部变化场景下省掉绝大多数更新 | 需要"入消息版本号"依赖计数 |
| **振荡抑制** | I4 | 检测"同一序列的消息被反复更新"（局部振荡），对其施加 (a) 噪声扰动 或 (b) 权重衰减 δ ← γ·δ（γ < 1） | 强行打破振荡、保证收敛 | 权重衰减会引入微小偏差，需在收敛后做若干次无衰减修正轮 |
| **Residual Splash（并行）** | I5 | 把残差较大的、**互不依赖的**若干条消息打成 "splash" 并行更新，理论最优并行度 | 多核/分布式下的近线性加速 | 需要依赖图与调度分组 |

> **I3 的先例价值**：在 LDPC 译码中，残差式 informed dynamic scheduling 比 flooding 少约一半迭代，且**单轮复杂度不变**（因为只是换顺序，不是多算）。这为"档 A 不改正确性、只改速度"提供了实证支撑。

#### A-4 复杂度

每次更新 O(log deg)（闭式 + 缓存维护）+ O(log m)（堆操作）。若一轮"等效同步迭代"含 m 次半消息更新，则轮代价 O(m log deg)。

### 3.3 档 B：warm start + 影响区域

#### B-1 初值复用

- P22 的零初始化是"最坏情形先验"：它等价于"没有任何信息"，因此需要走满定理给出的轮数。
- 本方案保留上一轮**收敛后的 δ 快照**，只把失效的半消息重置或修正。理论上界（P22 定理 1）与初值无关，因此**热启动绝不损害保证**，只会提前到达。

#### B-2 受影响集 S₀ 的定义（按触发类型）

| 触发 | S₀（需要重置/标记的半消息） |
|---|---|
| 单弧 e 权变 Δw | 仅 δ(e→i)、δ(e→j)（各加 Δw），残差 ｜Δw｜ |
| 加/删弧 e | e 的两条半消息 δ = 0；两端点 i, j 的**全部出半消息**标记失效 |
| k 或 f 变化 | 仅 s（及多源多汇的 S）与 t（及 T）的全部半消息 |
| 点/弧流式到达 | 新点及其 R-邻域内的半消息（I9） |

其余半消息**原值保留、入队优先级 = 0**（或按 A-3 的估计式给一个低优先级）。这就是"前沿之外不动"的实现形式。

#### B-3 与三类区域型方法的对位

| 方法 | 组织波前的方式 | 与本方案的关系 |
|---|---|---|
| **EFBP（I7 Nath 2010）** | 按**受影响区域**组织"扩张前沿"：只在前沿推进，并证明 EFBP 与标准 BP 的信念差有界 | 提供"只改局部"的**合法性界**；我们的优先队列边界即 EFBP 前沿 |
| **AdaBP（I8）** | 按**查询相关子图**组织：只更新与当前 query 有关的部分；树/高斯情形精确 | 对应我们"只关心某条弧/某几对路径"的场景（可作二期） |
| **Fan 2017（I13）** | 不按区域，而是给出增量算法的**可分析性判据**：localizable（代价由 ∆G 的 d-邻域决定）+ bounded relative（代价由 ∆G 与必然被检查区域的大小决定） | 给我们一个**理论表述模板**：把"我们的增量算法有效"写成"localizable + 相对批量有界"，而不是去证无法成立的严格 bounded（I13 明确指出图遍历/连通性等常见查询的增量问题是 unbounded 的） |
| **Sutton §4（I2）** | 当**因子本身变化**（如参数更新）时，给出残差的初始化方法 | 直接对应我们的"权变/删边"触发器的残差初始化 |

**推荐的融合表述（汇报用）**：*用区域给"初始优先级"，用残差给"动态优先级"*——初始化时只把 S₀ 及其 d-邻域以正残差入队（EFBP 思路，I7），随后完全由残差堆驱动（RBP 思路，I1），并用 Quiet 规则静默稳定区（I6）。

### 3.4 档 C：结构/参数变化的六个触发器

#### C-1 单弧权变（最常用、最容易讲清）

w(e) → w(e) + Δw（e = (a, b)）。由 §2.3(1)：

- δ(e→a) ← δ(e→a) + Δw，δ(e→b) ← δ(e→b) + Δw
- 两条半消息以残差 |Δw| 入队

**要点**：**顶点规则完全不需要重算**，因为依赖 w(e) 的只有 δ(e→·)。这是"权变"最廉价的原因，也是实验里最容易展示增量收益的场景。

#### C-2 加/删弧与加/删点

- 加弧 e = (a,b)：IN(b) ∪= {e}、OUT(a) ∪= {e}；δ(e→a)、δ(e→b) 按 §2.3(1) 用现有邻居 δ 初始化（而非硬置 0，可少迭代）；a、b 的全部出半消息以正残差入队。
- 删弧：从集合移除并**惰性删除**缓存项；a、b 的出半消息以正残差入队。
- 加点/删点：等价于批量加/删弧；注意维护"退化度"标记（OUT = ∅ 等）。

#### C-3 k 或 f 变化（增量收益最大的场景）

由 §1.1 的关键洞察（内部顶点局部规则**不含 f**）：

- k → k+1 或 k−1：只需重算 δ(s→·)（OUT(s) 全部）与 δ(t→·)（IN(t) 全部）
- 每次重算代价 O(deg(s)·log deg(s)) + O(deg(t)·log deg(t))，然后交给残差堆扩散
- 边界：若 k > |OUT(s)| 或 k > |IN(t)|，实例不可行 → 应直接报不可行（T = +∞ 会传染，不要让它进入迭代）

#### C-4 流式到达（I9 StreamBP）

I9 的 StreamBP（Algorithm 1）规则：节点 v(t) 到达时，**(1)** 更新所有指向 v(t) 的消息，(2)**沿从 v(t) 出发的路径按距离递增**做 R 层更新（R-local）。每次到达的总更新数 O(R·deg)。其理论结论是：在流式随机块模型下 StreamBP 达到与离线 BP 相同的渐近精度，而每次到达只做常数级更新。

> 移植到 k-VDSP：把"第 t 个到达的顶点"视为触发 S₀ = {新点及其 R-邻域内半消息}，其余复用。这给出了**"每步 O(R) 次更新的实时重规划"**这一 anytime 卖点。

#### C-5 预算受限 / 超大图（I11 LinBP/SBP）

I11 的 LinBP 把 BP 消息**线性化**成矩阵方程（闭式解、有收敛保证），SBP 则是"每条边至多传播一次"的局部版本，并明确支持**动态网络上的快速增量更新**。代价是牺牲精确性（只依赖最近的有标签邻居）。

> 移植：作为"预算受限模式"——当残差堆在给定时间预算内未清空时，用单遍线性化近似给出当前最优估计（anytime 输出），随后在后台继续跑精确的残差迭代。

#### C-6 通用增量求解框架（二期方向，I12 InCOpt）

I12 把"带硬约束的增量非线性优化"统一为**Bayes tree 上的上行/下行 pass**：线性系统 → Bayes 树；前代/回代 = 上/下行 pass；并支持 fluid/online relinearization（不必周期性批量重线性化）。

> 移植（有理论野心，列为二期）：对 k-VDSP 的因子图做变量消元 → 得到消元树（等价于 Bayes 树）；实例变化后只需**局部重排 + 局部上/下行 pass**，而不是全图异步迭代。这条路线把"增量式 BP"升级为"增量式因子图求解器"，也是最有论文空间的方向。

### 3.5 主算法（完整伪代码）

```
────────────────────────────────────────────────────────────
算法 INC-BP(k-VDSP)  增量式消息传递
输入: G=(V,E,w), s, t, k; 上一轮缓存 CACHE = {δ, 顶点有序表, 快照}
参数: eps(残差阈值), λ(阻尼), R(流式局部半径), ITER_MAX
输出: x ∈ {0,1}^m ; 或 INFEASIBLE
────────────────────────────────────────────────────────────
# ---------- 0. 实例校验 ----------
if k > outdeg(s) or k > indeg(t): return INFEASIBLE

# ---------- 1. 数据层 ----------
IN[i], OUT[i]           # 弧集合（哈希集）
IN_sorted[i], OUT_sorted[i]  # 按 δ 排序 + 前缀和（次序统计）
top3[i]                 # (min1,min2,min3) + argmin
delta[half_msg]         # 每条有向半消息一个 double
PQ                      # 最大堆，键 = |delta_new − delta_old|
version[half_msg]       # 用于 Quiet 的依赖版本号

# ---------- 2. 初始化 / 热启动 ----------
if CACHE 存在: 载入 delta, 重建 IN_sorted/OUT_sorted/top3（O(m log deg) 一次性）
else:          全部 delta = 0（冷启动，等价 P22 Alg.1 第 1 行）

# ---------- 3. 变化注入（三档触发器） ----------
对每个变化 Δ ∈ {w 变, 弧增删, 点增删, k/f 变, 流式到达}:
    按 §3.3 B-2（失效集定义）/ §3.4（触发器）计算 S₀；残差调度由档 A（§3.2）负责
    对 h ∈ S₀: delta[h] ← 修正值; PQ.push(h, |修正量|); version[h]++

if 无变化（纯冷启动）:
    for 全部半消息 h: PQ.push(h, +∞)

# ---------- 4. 残差驱动主循环（档 A） ----------
iters = 0
while PQ 非空 and iters < ITER_MAX:
    h = PQ.pop_max()                     # h = (i→e) 或 (e→i)
    old = delta[h]
    new = LOCAL_RULE(h)                  # §2.3：跨弧 / 内部 top-2 / 源汇 top-k
    r = |new − old|
    if r <= eps: continue                # Quiet: 静默，不再入队（I6）
    delta[h] = (1−λ)·old + λ·new         # 阻尼（λ=1 即无阻尼）
    iters += 1
    # 只把"真正受影响的"邻居重新入队（Quiet 的入版本号判据）
    for h' in AFFECTED_BY(h):
        if version_stale(h'): PQ.push(h', EST_RESIDUAL(h'))   # I2 的残差估计
    if 振荡检测触发: 应用噪声 或 δ ← γ·δ                     # I4

# ---------- 5. 解码 ----------
for e = (i,j) in E: Δ[e] = w[e] + delta[i→e] + delta[j→e]
    x[e] = 1  if Δ[e] < 0  else 0

# ---------- 6. 可行性与后处理 ----------
if not FEASIBLE(x): 
    降 eps 重跑 或 同步全扫若干轮兜底（等价 P22 Alg.1）
    # 注意：非负权下最优解无环，但中途解码可能出"孤立有向环"
    删除孤环（Kahn 拓扑排序找环 / DFS 找环）
if FEASIBLE(x): return x

# ---------- 7. 缓存写回 ----------
CACHE ← {delta, IN_sorted, OUT_sorted, top3}   # 供下一次变化热启动
────────────────────────────────────────────────────────────

子过程 LOCAL_RULE(h):
  h = (i→e)，e=(a,b)：
  if h 是 (e→i): return w[e] + delta[另一端→e]        # §2.3(1)
  if i 是内部顶点:                                      # §2.3(2)
      p_in  = top3_IN[i] 排除 e（若 e∈IN[i]）
      p_out = top3_OUT[i] 排除 e（若 e∈OUT[i]）
      return p_out − min(0, p_in + p_out)  若 e∈IN[i]
      return p_in  − min(0, p_in + p_out)  若 e∈OUT[i]
  if i == s: return T(k−1, OUT[s]∖{e}) − T(k, OUT[s]∖{e})
  if i == t: return T(k−1, IN[t]∖{e})  − T(k, IN[t]∖{e})
```

### 3.6 缓存维护的坑（实现时必须处理）

1. **惰性删除**：删弧后不立即从有序表物理删除，而是打删除标记 + 版本号；达到阈值（如删除占比 > 30%）再重建。
2. **BIG 溢出**：用 BIG = 1e15 代替 +∞；只要一条 δ = BIG，任何包含它的加法都可能溢出 ⇒ 在 T(·)/pᵢₙ 计算中先做"可行性短路"（若 k > 可用弧数直接判不可行）。
3. **静默消息的唤醒**：Quiet 剪枝必须维护"入消息版本号"，否则会漏更新（I6 的正确性依赖"入消息未变"这一事实）。
4. **权重衰减的收尾**：I4 的权重衰减会留下小偏差，建议收敛后关掉衰减、再跑若干轮纯残差迭代。
5. **数值归一化**：每若干轮对全体 δ 减去公共均值（§2.2 的 gauge 自由度允许这么做），防止量级漂移。
6. **s/t 的 k 边界**：重建缓存后**先**检查 deg 与 k 的关系，再进入迭代。

## §4 理论分析：增量式到底改变了什么、没改变什么

### 4.1 不动点不变性（四条引理）

**引理 A1（初值无关）**：BP 的不动点方程（式(6)(7) 令 m(new) = m(old)）中不含初始值。⇒ 换初值不移动不动点。
依据：#5 Weiss&Freeman 的不动点方程视角；#2 GDL 的消息等价类。

**引理 A2（阻尼不改不动点）**：δ ← (1−λ)δ(old) + λ·δ(new) 在 δ(old) = δ(new) 处是恒等映射。⇒ 阻尼只改变到达路径，不移动终点。

**引理 A3（合理的异步调度收敛到同一不动点）**：**I1 Elidan 2006 的定理**——任何"合理的"异步 BP（无饥饿、以固定点方程更新）在与同步 BP 收敛性相同的条件下收敛到**唯一**不动点；且简单 round-robin 调度的收敛速率不劣于同步。

**引理 A4（热启动等价于换初值）**：档 B 的 warm start 只是把初值从 0 换成上一实例的收敛值，属于 A1 的作用范围。
**推论**：三档叠加后，算法停在的仍是 (G, w, f) 的 BP 不动点；在 P22 唯一最优条件下，该不动点解码即 x⋆。

### 4.2 轮数上界与增量收益（要诚实表述的三点）

**定理 B1（上界继承，不是上界改进）**：增量的收益**不体现**在最坏情况轮数上。P22 定理 1 的 (⌈U/(2o(x⋆))⌉+1)·n 上界对任何合理调度都成立（§1.5 的证明骨架不依赖初值与顺序），因此我们的增量算法在最坏情况下仍受同一上界约束。我们要主张的是**实际更新次数**与**单次更新代价**的下降。

**命题 B2（收益模型）**：设变化集为 ∆G（大小 c），问题在半径 r 的邻域上可**局部化**（I13 的 localizable 定义）。则

- 冷启动：需 Θ(m) 次半消息更新（含全部顶点规则重算）
- 热启动：期望 Θ(|S₀| · degʳ) 次更新，其中 S₀ 是失效半消息集（§3.3 B-2）

在稀疏图 + 局部变化下 |S₀| · degʳ ≪ m，这就是增量式的立足点。表述模板直接借用 **I13**：把结论写成"该增量问题是 localizable 的、且相对批量算法有界"，而**不要**去证严格 bounded（I13 用图遍历/连通性/关键词搜索的反例说明常见查询的增量问题是 unbounded 的，硬证 bounded 是走不通的路）。

**命题 B3（摊销）**：若连续 T 次局部变化，则总量约为 O(T · |S₀| · degʳ)，而批量重解为 O(T · m)。这正是"动态图实时重解"场景的卖点（对应 P22 §VI 强调的"分布式、易并行"）。

**与 I9 的对齐**：I9 StreamBP 给出了"每次到达只做 O(R) 次更新且渐近精度不降"的严格结论。我们的 C-4 触发器是该结论在 k-VDSP 上的移植（R 层邻域 = R-local），可作为理论部分的对照引文。

### 4.3 三个风险与对策

| 风险 | 具体表现 | 对策 | 依据 |
|---|---|---|---|
| **唯一性假设不成立** | 多最优解时 BP 可能振荡或落到不同不动点 | (a) 对权重加极小微扰打破对称（Isolation Lemma 思想）；(b) 报告"不唯一率" | #16/#17 Gamarnik 2012（FPRAS 用隔离引理保证唯一性）；P22 定理前提 |
| **假不动点** | 残差全为 0（δ 不变）但解码不是最优——异步调度停在"局部稳定点" | 安全网：周期性同步全扫 + 唯一性检测；把"解码不可行"当作继续迭代的信号 | #16 推论 5.2（整数数据跑 n²cₘₐₓ+n 轮可用信念差检测唯一性） |
| **振荡 / 数值漂移** | 有环图上残差调度反复更新同一序列；δ 量级随迭代增长 | λ 阻尼 + I4 的噪声/权重衰减 + 每若干轮整体平移归一化（利用 §2.2 的 gauge 自由度） | I4 Knoll 2015；I1 Elidan 2006 |

**补充风险（必须向导师明说）**：RBP 在**一般图（带环）**上没有普遍的收敛保证，I4 明确报告了 RBP 在局部振荡下失败的情形。因此本方案的收敛保证来自"**档 A + 周期性同步兜底**"的组合，而不是单靠 RBP。

### 4.4 正确性验证（三重）

1. **对拍精确最优**：与拆点 + 最小费用流的最优值/最优解比较（§5.1）。要求：**代价相等**；解不唯一时比较代价而非解。
2. **不变量自检**：每个中间状态检查 Σ(in) x = Σ(out) x（内部顶点）、s 出度 = k、t 入度 = k、内部度和 ≤ 2。
3. **实现交叉验证**：先用"完整 2 值消息 + 朴素枚举 min"实现一版（正确但慢），与"δ 标量化 + 闭式"版本逐轮对拍 δ 值——这是 §2.2 引理 1 的实证检验。

## §5 实验设计（增量式的卖点必须靠这里立住）

### 5.1 精确基线：拆点 + 最小费用流（必须做）

- 构造：对每个内部顶点 v 拆成 v(in) → v(out)，容量 1、代价 0；每条原弧 (u,v) 变成 u(out) → v(in)，容量 1、代价 w(e)；s 只保留出、t 只保留入；从 s 向 t 送 **k 单位流**。
- 节点/边容量 1 + 流守恒 ⇒ 恰好刻画"内部顶点不相交"；最小费用 ⇒ 最小总权。
- 工具：networkx `min_cost_flow`（或 OR-Tools / scipy `milp`）。
- **重要说明（要写进论文与汇报）**：**无长度约束的 k-VDSP 是多项式可解的**（P22 自己把问题溯源到 Suurballe 1974）。因此：
  - 把 MCMF 作为**正确性对拍的黄金标准**是完全合法的；
  - 但**不能**以"求解 NP-难问题"作为卖点，卖点必须是"动态/增量/分布式场景下的重解代价"。
- P22 §VI 原文也承认"running time is not better than that of other existing algorithms"，与上面一致。

### 5.2 图族与规模

| 图族 | 生成方式 | 用途 |
|---|---|---|
| ER 有向图 | G(n, p)，p 使平均度 ∈ {4, 8} | 主实验 |
| 分层网格（layered grid） | L 层 × W 宽，层间全连或稀疏连 | 模拟通信/路由场景；局部变化影响面可控 |
| 随机加权有环图 | ER + 保证存在环 | 检验振荡与阻尼 |
| 近平面/含瓶颈图 | 少量桥接节点 | 检验"变化影响区域"的大小分布 |

规模：n ∈ {20, 50, 100, 200}；k ∈ {2, 3, 5}；权 w(e) ~ U{1, …, 100}（整数，满足 P22 推论 2 的前提）。

### 5.3 变化模式（对应 §3.4 的触发器）

| 编号 | 变化 | 增量触发器 |
|---|---|---|
| Δ1 | 单条弧权 +δw | C-1 |
| Δ2 | 随机的 10% 弧权变化 | C-1 × 批量 |
| Δ3 | 随机增/删 5% 弧 | C-2 |
| Δ4 | k → k+1 或 k−1 | C-3 |
| Δ5 | 流式加入 20% 顶点与对应弧 | C-4 |
| Δ6 | 混合（Δ1+Δ4） | 组合 |

### 5.4 指标

- **消息更新次数**（核心指标）、**等效迭代轮数** = 更新次数 / 消息总数
- **墙钟时间**、**相对批量重解的加速比**
- **代价差**（与 MCMF 最优值之比 / 绝对差）、**最优命中率**
- **可行率**（解码结果是否满足约束）、**收敛率**（残差是否在预算内清零）
- **影响区域大小分布**（S₀ 的实际规模，用来验证 §4.2 的收益模型）

### 5.5 消融

| 消融项 | 对比 |
|---|---|
| 阻尼 λ | 0.5 / 1.0 / 自适应 |
| 调度 | 同步 vs RBP（I1） vs RBP + Quiet（I6） |
| 初值 | 零初始化（P22） vs 热启动（档 B） |
| 残差获取 | 真算（RBP1L） vs 估计（RBP0L, I2） |
| 并行 | 单线程 vs residual splash（I5） |

### 5.6 延伸：真正 NP-难的变体（决定论文档位）

若给 k-VDSP 加**长度约束**（每条路径长度 ≤ L，Itai–Perl–Shiloach 1982 的版本），问题变成真正 NP-难。此时：

- 基线换成 ILP/CP-SAT（小规模精确）或近似算法；
- BP 只能作启发式 → 但"**增量式 + anytime 实时重规划**"的价值此时最大；
- 这一路线与 P22 的 NP-难表述自洽，也是把工作升级为一篇独立小论文的最短路径。

## §8 需要与导师确认的问题清单

1. **研究定位**：我们打的是**无长度约束的 k-VDSP**（多项式可解，卖点在增量/动态/分布式），还是要往**带长度约束的真 NP-难变体**走？后者需要重新选基线（ILP/CP-SAT）并会改变论文的叙事。（依据：P22 引文 [16] 与 [25] 的分歧，见 §0.3 第 3 条）
2. **增量目标**：优先"动态图上单次变化的重解代价"（工程价值），还是"摊销复杂度 / 局部化的理论刻画"（理论价值）？两者实验设计不同。
3. **是否补齐 P22 的缺口**：P22 的消息初值、调度、停止判据、Lemma 4 的证明跳跃——我们是"在论文里替它补齐并作为我们的前置贡献"，还是"只当实现细节、不进论文"？
4. **是否延伸多源多汇**（P22 §V）：这个方向实现成本低（只改 s/t 规则），但需要把"双向 f-顶点"的局部规则补全（§2.3(5) 已列出）。
5. **是否二期做消元树/Bayes 树路线**（I12）：理论上最漂亮（把增量式 BP 升级为增量式因子图求解器），但工作量显著更大。
6. **是否需要 Excalidraw 架构图**：若要在汇报中展示"三档增量 + 数据流"，我可以按库内约定出一张 Excalidraw 图（库内约定：作图必须用 Excalidraw，不用 Mermaid）。
